Sugar Pebbles — Quick Guide & Shortcuts

Tools & Navigation

B or P — Paint wells (click or drag)

E — Dedicated Erase mode (any ROI)

G — Flood fill empty area or convert ROI

X — Flood erase connected ROI wells

H or hold Space — Pan view

[ / ] — Shrink / grow brush size

Scroll wheel — Zoom at cursor

F or 0 — Fit array to view

Editing & Files

⌘/Ctrl+Z — Undo

⌘/Ctrl+Shift+Z or ⌘/Ctrl+Y — Redo

⌘/Ctrl+O — Open cell table

⌘/Ctrl+S — Save session JSON

⌘/Ctrl+E — Export cell segmentation CSV

Double-click any ROI name to rename it inline.

Input Files

Any .csv, .tsv, or whitespace .txt with cell ID, X/Y coordinates, optional well/array/chip columns, and covariates.

Optional metadata: JSON (colors, meta, array, chips) or 2-column value,color CSV/TSV.
